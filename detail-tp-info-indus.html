Project Context

This project was my first immersion in C programming on a microcontroller. As part of my GEII studies, I developed the software architecture of an embedded system on an STM32 from scratch. Technically, the program retrieves analog data from a generator, processes it, and communicates via the I2C bus to write these values in real-time on an OLED screen. In parallel, the system manages power control by sending a calculated and adapted PWM signal to an H-bridge to drive a motor. I also configured a UART serial connection to transmit data and debugging frames to the PC. It's an excellent synthesis connecting low-level code, interrupts, and hardware protocols. If you'd like more details, take a look at my report!

Visible elements in the demonstration

  • OLED Screen — Title, PWM duty cycle, rotation direction, speed in RPM.
  • LED Bar Graph (VU meter) — Visual indicator of the speed setpoint.
  • Push Buttons — Manual control (acceleration, deceleration, direction reversal).
  • Microcontroller Board — STM32 motherboard (processing and central control).
  • Motor / Generator Assembly — Mechanical system (actuator and analog speed sensor).
  • H-Bridge — Power board (power interface between board and motor).
